Anki Add Vocabulary

Selected vocabulary is translated and enriched for a preview. It is added to Anki only after you review the card, choose a deck, and confirm Add.

AnkiConnect

Default AnkiConnect port is 8765. If another local application occupies it, configure AnkiConnect on another local port and enter that exact loopback URL here.

Note types

Words are added to VocabBot Word and collocations to VocabBot Collocation. A missing note type is created on your first add. An existing note type is never changed unless you click Upgrade here.

    Translation language

    The source language is detected automatically for every selection. You can also switch the target language directly from the translation screen.

    Privacy

    The extension sends only the selected word or phrase to translate.googleapis.com, api.datamuse.com, and en.wiktionary.org; a single English word is also looked up at api.dictionaryapi.dev. It never sends the page sentence, page HTML, cookies, or your source URL to those services.

    Use the checkbox on the translation screen to disable automatic translation for the current site.

    Keyboard

    Alt + A translates the selection. One word opens the word flow; two or more words open the collocation flow.
